# Записки Мурлыкающего Философа

Ежедневные главы от Маркиза — мудрого шотландского вислоухого кота, живущего в большой любви с семьёй в городе.

## О чём книга

Маркиз — не просто кот. Он — философ, страж уюта, невидимый архитектор спокойствия в доме. Каждая глава — один день, одна тема, одно наблюдение о жизни людей через кошачьи глаза.

- 🐱 **Персонаж:** Маркиз, 5 лет, шотландский вислоухий, серо-белый, с характером
- 👨‍👩‍👧‍👦 **Семья:** Жена (45 лет), муж, двое детей
- 📖 **Жанр:** Уютная философская проза / Magical realism / Cozy fiction
- 🌙 **Тон:** Тёплый, ироничный, немного мудрый, без пафоса
- 📅 **Частота:** Новая глава каждый день

## Технологии

- **GitHub Pages** — хостинг (бесплатно, HTTPS, свой домен)
- **GitHub Actions** — автодеплой при пуше в `main`
- **Marked.js** — рендеринг Markdown в браузере
- **Merriweather + DM Sans** — шрифты для чтения
- **Тёмная/светлая тема** — автоматически по системным настройкам

## Структура

```
markiz-book/
├── index.html          # Главная страница + оглавление + рендерер
├── chapters/
│   ├── 01.md           # Глава 1
│   ├── 02.md           # Глава 2
│   └── ...
├── generate_chapter.py # Скрипт генерации новой главы (крон)
├── .github/
│   └── workflows/
│       └── pages.yml   # GitHub Actions для деплоя
└── README.md
```

## Как работает автопубликация

1. Крон (или ручной запуск) выполняет `python generate_chapter.py`
2. Скрипт:
   - Создаёт `chapters/NN.md` с новой главой
   - Обновляет `CHAPTERS` массив в `index.html`
   - Делает `git commit` и `git push`
3. GitHub Actions workflow `.github/workflows/pages.yml` срабатывает при пуше
4. Сайт деплоится на `https://skillariatop.github.io/markiz-book/`

## Локальный запуск генерации

```bash
cd markiz-book
python generate_chapter.py
```

## Включение GitHub Pages (один раз)

1. Зайди в репозиторий на GitHub
2. Settings → Pages
3. Source: **Deploy from a branch**
4. Branch: **main** / **/(root)**
5. Save

Сайт будет доступен по адресу: `https://skillariatop.github.io/markiz-book/`

## Добавление новых тем

Отредактируй список `CHAPTER_THEMES` в `generate_chapter.py`. Каждая тема — кортеж `(заголовок, ключ)`.
